# The Trust Gradient

## Cognitive Load and Friction in Debugging AI-Generated Code

This UX research case study investigates how GitHub Copilot changes developer cognition during debugging. Using Think-Aloud studies, NASA-TLX, and Retrospective Cued Recall, the research uncovers how automation bias and cognitive load affect developer behavior.

## Research Methods
- Think-Aloud Testing
- NASA-TLX
- Retrospective Cued Recall
- Developer Interviews

## Key Findings
- Phantom Familiarity
- Automation Bias
- Cognitive Load Relocation
- AI Trust vs Behavioral Trust

## Design Recommendations
- Risk-based AI suggestion highlighting
- Mandatory review pause
- AI-origin gutter indicators
